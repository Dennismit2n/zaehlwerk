Zählwerk

Deine Claude-Code-Nutzung in Zahlen

Ordner auswählen und loslegen

Zählwerk liest die Protokolle, die Claude Code auf deinem Rechner anlegt, und rechnet aus, wohin dein Verbrauch geht. Die Dateien bleiben dabei auf deinem Gerät — es gibt keinen Server, der sie entgegennehmen könnte.

Ordner hierher ziehen oder klicken

Es werden ausschließlich .jsonl-Dateien gelesen

Wo liegt der Ordner?

Windows%USERPROFILE%\.claude\projects
macOS / Linux~/.claude/projects

Der Ordner ist versteckt, weil sein Name mit einem Punkt beginnt. Im Explorer den Pfad einfach oben in die Adreßleiste eintippen; im Auswahlfenster genügt es, ihn dort einzufügen.

Lieber live nebenher statt Rückschau?

Der Zählwerk Ticker ist eine kleine schwebende Anzeige für Windows: laufendes Fünf-Stunden-Fenster, Tagessumme, Modelle. Liest dieselben Dateien, ebenfalls ohne Netzzugriff.

Auf einen Blick

Heute –
Diese Woche –
Verbrauch gesamt –
Kontext erneut gelesen –
Was bedeuten diese Zahlen?

Verbrauch gesamt zählt zusammen, was neu entstanden ist: was du getippt hast, was Claude geschrieben hat, und den Gesprächsverlauf, der neu in den Zwischenspeicher gelegt wurde.

Kontext erneut gelesen steht bewußt daneben und nicht darin. Bei jeder Folgefrage wird der bisherige Verlauf noch einmal mitgezählt. Diese Zahl wächst also mit der Länge einer Sitzung, nicht mit deiner Arbeit — sie ist meist zwanzig- bis dreißigmal so groß wie der eigentliche Verbrauch und würde jede Gesamtsumme unbrauchbar machen.

Ein Token ist grob ein halbes Wort. Genaue Kosten kann Zählwerk nicht ausrechnen: In den Protokollen steht kein Preis, und im Abonnement kostet Claude Code ohnehin nichts zusätzlich.

Die letzten 30 Tage

Wie liest man das?

Ein Balken je Tag, von links nach rechts bis heute. Die Höhe zeigt den Verbrauch dieses Tages im Verhältnis zum stärksten Tag des Zeitraums. Tage ohne Balken sind Tage, an denen du nicht mit Claude Code gearbeitet hast.

Nach Modell

Warum ist das interessant?

Die verschiedenen Modelle sind unterschiedlich schnell und unterschiedlich gründlich. Wenn ein einzelnes Modell fast deinen ganzen Verbrauch ausmacht, lohnt der Gedanke, ob für einfache Arbeiten ein kleineres genügt.

Nach Arbeitsordner

Woher kommen diese Namen?

Aus dem Verzeichnis, in dem Claude Code jeweils gestartet wurde. Gezeigt wird nur der letzte Ordnername — und nur dann mehr, wenn zwei Ordner sonst gleich hießen.

Wenn hier fast alles unter einem einzigen Eintrag steht, heißt das schlicht, daß du Claude Code meist aus demselben Verzeichnis heraus benutzt.

Nach Tageszeit

Wie liest man das?

Vierundzwanzig Säulen, eine je Stunde deines Tages, über den gesamten Zeitraum aufsummiert. Zeigt, wann du tatsächlich arbeitest — nicht wann du glaubst zu arbeiten.

Was ist eine Sitzung?

Ein durchgehendes Gespräch mit Claude Code. Die Dauer ist der Abstand zwischen der ersten und der letzten Antwort — Pausen dazwischen zählen mit, denn Zählwerk kann nicht wissen, ob du Kaffee geholt oder nachgedacht hast.

Nach Git-Zweig

Wozu das?

Claude Code merkt sich, auf welchem Git-Zweig gearbeitet wurde. Wer je Aufgabe einen eigenen Zweig anlegt, sieht hier, welche Aufgabe wie viel gekostet hat. Ohne Git bleibt die Liste leer.

Was gelesen wurde

Warum stehen hier zwei verschiedene Zahlen?

Eine einzelne Antwort steht mehrfach in den Protokollen — einmal je Block, aus dem sie besteht: Nachdenken, Text, Werkzeugaufruf. Jede dieser Zeilen trägt die vollständige Abrechnung der ganzen Antwort.

Zählwerk erkennt das und zählt jede Antwort genau einmal. Würde man einfach alle Zeilen zusammenzählen, kämen ungefähr doppelt so hohe Zahlen heraus.
